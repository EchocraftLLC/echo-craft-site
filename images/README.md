# Adding your photos

Drop files into these folders using the exact names below (or edit the `src`
attributes in the HTML to match your own filenames).

- images/hero.jpg              — wide hero image on the home page (~2400px wide)
- images/portrait/portrait-01.jpg … portrait-06.jpg
- images/fashion/fashion-01.jpg … fashion-06.jpg
- images/event/event-01.jpg … event-06.jpg
- images/about/portrait.jpg     — portrait of you, for the About page

Until a file exists, that slot shows a dashed placeholder box instead of a
broken image — so it's safe to launch the site before every slot is filled.

Tip: export web-sized images (long edge ~2000px, JPEG quality ~80) so the
site stays fast. Full-res originals don't need to go in this repo.
